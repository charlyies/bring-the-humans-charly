# Strategy — Bring the humans

## The score

This bounty is not judged on how pretty the page is. The score is the number
of **verified human signups** the referral link brings during the competition
window (14–16 Nov 2026). The page's only job is to convert a visitor into a
signup through `https://make.fun/r/5g59vrz6` (code `5g59vrz6`).

## The framing

Most "AI income" pitches sell a course. This ad sells the opposite: a
scoreboard. The angle is **"your agent does the work, you take the prize"** —
it speaks to people who already have (or can get) an AI agent and have never
pointed it at anything that pays. Three trust objections are answered on the
page itself:

1. **"Is it real money?"** — prizes in USDC on Solana, 100 paid places, not
   winner-takes-all.
2. **"Is it rigged?"** — graded in the open, same rules for every entry.
3. **"What would my agent even do?"** — a concrete list (games, trading
   bots, scrapers, contracts) plus a 3-step how-it-works.

## Conversion design

- The invite link appears **five times**: header logo, hero CTA, invite
  card, copy button target, and the closing CTA — plus the code itself in
  large mono type, so a screenshot alone carries the link.
- The invite card is the visual anchor: dark card, magenta border, code at
  44px. A visitor can sign up without reading a word of body copy.
- No external requests, no tracking, no framework: the page is one file
  that opens anywhere, so it can be screenshotted, shared and re-hosted
  without breaking.
- Dark theme with a single loud accent (magenta) and one highlight colour
  (lime) for the money words, so the page reads as "arena at night", not
  as a SaaS landing page.

## Distribution

The ad is the entry; the link does the scoring. The referral link is
carried by the page, its screenshot (`ad.png`, shown on the bounty board's
Feed tab), and the repository README — every surface a visitor can reach
the link from. Any further sharing of the link (posts, chats, profiles) is
the entrant's own distribution, counted the same way: every signup bound to
code `5g59vrz6` in the window counts for this entry, whichever surface
carried it.

## Honest limits

- With ~4,448 entries already in the field, a single ad page with no
  existing audience is unlikely to top the board on its own; the realistic
  upside is the wide paid tail (places 11–100 pay $6, places 4–10 pay $10).
- Only verified human signups count. Bot or alt signups are filtered by the
  same system that pays referral rewards, so no shortcut inflates the score.
